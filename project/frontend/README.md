# 견적 아카이브 AI — 기존 견적 데이터베이스

기존 견적서 업로드 → 정보 추출 → 원본 대조 및 추출 오류 정정 → 검색·목록·상세·원본 조회를 위한 한국어 React/Vite 프론트엔드입니다. 기본 화면은 견적 보관함이며 모든 자료는 실제 백엔드 API에서 조회합니다.

## 실행

Node.js 24 / npm 11. 이 폴더에서 `npm install`, `npm run dev`를 실행합니다. 기본 주소 http://127.0.0.1:5173, 백엔드 http://127.0.0.1:8000. `/api`는 Vite 프록시로 연결합니다. 다른 백엔드는 `.env.example`의 `VITE_API_BASE`에 주소를 설정하거나 `API_PROXY_TARGET`으로 프록시 대상을 변경합니다. `npm run build`로 production 빌드를 검증합니다. production 배포에서는 백엔드가 빌드 결과를 제공하거나 빌드 전에 API 주소와 CORS를 설정해야 합니다.

## 제공 화면

- 견적 보관함: 다중 파일/드래그 등록, data 원본 등록, 거래처·담당자·연락처·제목·품목·날짜·원본 금액·검토 상태 검색.
- 상세: 원본 PDF/이미지/파일, 추출 원문, 원본 헤더와 모든 품목·선택 조건·세부 부품 관계, 추출 정보 정정, 검토 완료, 정정 이력 비교.
- 품목·단가 이력: 원본의 모든 선택 옵션과 부품을 포함해 규격·수량·단위·통화·원본 단가·납기·결제 조건 조회.
- 등록 현황: 문서수, 검토 필요, 거래처수, 원본 품목수.
- 자연어 검색: 저장 문서의 담당자·제목·품목·날짜 조건을 해석하고 근거 문서 표시.

수량이나 단가 정정이 다른 금액을 자동으로 바꾸지 않습니다. 원본에 없는 세율·세액·총액은 빈값으로 유지합니다. VAT 별도 문서는 공급가액 기준을 표시하고, 옵션이 있어 합계가 없는 문서는 '원본 합계 미기재'로 표시합니다. 추출 정보 정정은 DB에만 반영하며 원본 파일은 변경하지 않습니다.

신규 견적 생성, 복사, 가격 산정, 출력 양식, 새 Excel/PDF 출력, 영업 수주 상태 기능은 이 아카이브의 범위에 포함하지 않습니다.
