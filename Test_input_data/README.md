- expected_results.json은 원본의 정답 데이터입니다. 앱의 추출 결과와 별도로 비교하세요.
- 옵션 문서의 모든 행을 보존하되 선택 전 합계를 생성하지 마세요.
- 패키지 구성품을 상위 패키지 금액에 다시 더하지 마세요.
- 오류·누락 문서는 원본 값을 보존하고 검토 후 수정하는 흐름을 확인하세요.

- 현재 앱의 PDF 추출은 담당자·전화·이메일을 자동 반영하지 않으므로 원본을 보고 확인해야 합니다.
